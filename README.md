# Predicting Student Marks Using Linear Regression

## Description

A machine learning project that predicts student marks based on study time and the number of courses using Linear Regression.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Dataset

The dataset contains information about the number of courses, study time, and student marks.

## Methodology

* Data loading and preprocessing
* Exploratory data analysis
* Feature selection
* Linear Regression model training
* Model evaluation using R² score
* Prediction of student marks

## Features

* Number of Courses
* Study Time

## Target

* Student Marks

## Result

The Linear Regression model achieved an R² score of approximately **0.97**, indicating a strong fit between the input features and predicted student marks.
